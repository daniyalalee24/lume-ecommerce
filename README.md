# LUMÉ — E-Commerce Web Application

LUMÉ is a full-stack e-commerce web application built with the MERN stack. It includes user authentication, product browsing, cart management, checkout, order management, and an admin dashboard.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB

## Features

- User registration and login
- JWT-based authentication
- Product browsing and management
- Shopping cart
- Checkout and order management
- Admin dashboard
- Protected admin routes
- Responsive UI
